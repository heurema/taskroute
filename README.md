# TaskRoute

A small Codex plugin for bounded Python delivery through Claude Code, with separate
review, deterministic checks and compact final acceptance.

The self-contained version **0.1.0** is in [plugins/taskroute](plugins/taskroute/README.md).
Start there for supported scope, preparation, execution, tests and limitations.

Licensed under MIT. This repository is prepared locally; no hosted service or
account setup is required by the package.
